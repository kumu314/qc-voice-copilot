# #13 质检语音随检录入

> AI 黑客松作品 · 5 人队 · 赛道以提交填报为准

边测边说，自动填检验表并标出不合格项。质检员在现场按项口述实测值，系统把语音转成结构化检验记录，自动填入表格、标出超差项，并导出可交付的检验单。

## 快速开始

**双击 `index.html`。** 不需要安装、不需要联网、不需要账号。

- 运行时只要求一个现代浏览器（Chrome / Edge 最新版）。
- 不需要 Node、npm install、数据库、Docker、Python。
- 现场使用统一设备，`file://` 双击即可演示。

## 为什么是纯静态

赛制要求材料在 12:00–13:00 前拷到现场统一设备。纯静态产物拷过去就能跑，不依赖服务端、账号或网络；开发期用的工具链打包后全部消失，现场不带任何运行环境。

## 主链路（不挑设备）

`MediaRecorder` 录音 → 预置转写结果 + 手动改字 → 结构化填表 → 标出不合格项 → 导出检验单。

实时语音识别（`webkitSpeechRecognition`）只作加分项：它只有特定浏览器提供且依赖厂商云端服务，挑设备，不能作为主链路。

## 数据合规

只用模拟或脱敏数据，演示时口播「样例数据」。不得使用企业真实敏感数据，不得带出场地。**本仓库为 public，任何真实数据入库即等于带出场地。**

## 当前原型（第一版演示）

| 文件 | 作用 |
|---|---|
| `index.html` | 启动页：分别打开两端，或「同时打开两端」左右并排 |
| `screen.html` | 主管驾驶舱（投影 / 大屏）：实时识别管线、检验表、异常复核、证据追溯、整改与报告、验证看板 |
| `phone.html` | 质检员手机端：大字读数、语音回读、超差即时提醒、本次记录 |
| `engine.js` | 两端共用引擎：术语识别（别名 → 拼音模糊 → 纠错表）、中文数字解析、规则判定、跨项一致性、可信度提示 |
| `server.mjs` | 可选：零依赖 Node 联动服务器，让真手机和投影电脑跨设备同步 |

**用法**

- 同一台电脑：双击 `index.html` → 「同时打开两端」。两个窗口通过 `BroadcastChannel` 联动，断网可用；手机端晚打开也会补齐之前的记录。
- 真手机 + 投影（可选）：`node server.mjs`（默认 8080 端口，`PORT=9000 node server.mjs` 可改），手机与电脑连同一 Wi-Fi，打开终端打印的 `phone.html` 地址。
- 大屏快捷键：空格 自动播放剧本，→ 单步，R 重置，H 隐藏底部控制台，1–5 切换视图。手机端点麦克风推进剧本。
- 接入真实识别：识别出文字后调用 `QCE.send({t:'utt', text})`，走同一条纠错 → 判定 → 回读管线。

**注意**

- 检验项、公差、配置值、验证看板指标全部是**占位 / 示意数据**，界面上已标注，待换成企业确认后的脱敏规则。
- 剧本里的语音是文字模拟，尚未接入 `MediaRecorder` 录音。
