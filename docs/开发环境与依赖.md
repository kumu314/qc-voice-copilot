## 开源项目：必需 / 可选 / 明确不用

### 必需：零个第三方运行时库

浏览器原生能力已经够：`MediaRecorder`（录音）、Web Audio API（可选波形）、`Blob` + `a[download]`（导出）、Canvas、localStorage。

刻意不引第三方库，理由三条：`file://` 下 ES module 与 `fetch` 会被拦；断网时 CDN 会白屏；每多一个库就多一份随包体积与许可核对。

### 可选（要连代价一起看）

| 项目 | 解决什么 | 代价 | 建议 |
|---|---|---|---|
| RecordRTC | 抹平 `MediaRecorder` 的浏览器差异 | 多一个随包 js；必须本地打包、不用 CDN | 仅当实测发现兼容问题再引 |
| SheetJS (`xlsx`) | 导出 `.xlsx` 检验表 | 体积大、许可需核对、`file://` 下要传统 script 引入 | 先用 CSV + 浏览器打印 PDF，够用就不引 |
| `chrome-headless-shell` 自动化脚本 | 交付前批量截图与断言 | 只跑在开发机，不进产物 | 用现成 skill 驱动，不自己装 playwright |
| Vite 等构建器 | 模块化开发、热更新 | 引入 `node_modules`；产物要注意 base 路径与 module 类型，容易在 `file://` 下踩坑 | **明确不用** |

### 明确不用（别让队友去装）

- React / Vue / 任何 UI 框架、任何 CSS 框架 CDN、Google Fonts、图标库 CDN。

## `file://` 打包规约（必守）

双击本地 HTML 时地址是 `file://`，四条浏览器限制会让「拷过去就能跑」失效：

| 限制 | 后果 | 写法 |
|---|---|---|
| `fetch()` / XHR 读本地 JSON 或 PDF | CORS 拦掉，白屏 | 数据内联成 `window.DEMO_DATA`，或 `<script src="data.js">` |
| `type="module"` 的 ES module | `file://` 下加载报错 | 用传统 `<script>`，靠全局变量或 IIFE 组织 |
| `getUserMedia` / `MediaRecorder` | 部分浏览器不给权限（**未实测**） | 本机 `file://` 实测一次；不通就走「预置转写 + 手动改字」 |
| 挂 CDN 的脚本 | 断网或企业网络拦截即白屏 | 所有库随包放 `vendor/`，相对路径引入 |

验收动作固定为：拷到另一台机器 → 断网 → 双击 `index.html` → 走完主流程。

## 基线（什么都不做的代价）

**维持现状是合法选项**：不写这份文档、不统一打包写法，三件照样能开工。不动的代价是三处：

- 有人用 `fetch` 读本地 JSON 或 `type="module"`，dev server 下正常、现场 `file://` 白屏，而这类问题到现场才暴露；
- 队友各自决定要不要引第三方库，产物里混进 CDN 链接或 `node_modules` 依赖；
- public 仓库里没人统一提醒数据合规，容易带进真实检验表或现场照片。

补这份文档只增加一份阅读成本，不改变运行时依赖，也不需要安装任何东西。

## 为什么选纯静态（比较依据）

相比两种常见替代，取舍落在可比较的维度上：

| 对比维度 | 纯静态（本方案） | 带服务端 / 构建器 |
|---|---|---|
| 现场拷过去能不能跑 | 双击即演，零调环境 | 要提前调通环境与账号，窗口只有一小时 |
| 断网 / 企业网络拦截 | 不受影响 | CDN 或云 API 被拦即失效 |
| 设备差异 | 只用浏览器原生能力 | 依赖现场浏览器版本与 runner |
| 功能天花板 | **吃亏**：做不了真正的实时语音识别、服务端推理 | **占优**：能接模型、能存库 |
| 开发体验 | **吃亏**：没有模块化与热更新，代码组织靠约定 | **占优**：Vite / 框架的开发效率 |

因为赛制把「材料拷到统一设备、一小时内调环境」设成硬窗口，而 6 分钟展示只需要主流程跑通、有界面、有数据，纯静态在「现场可跑」这个决定成败的维度上占优，在功能天花板与开发体验上吃亏。这个取舍可以反悔：若现场实测允许带环境，可选路线里那两项加分能力可以再开。

## 失效边界

- 若后来加了服务端能力（真接模型 API、上数据库），运行时零依赖这条即不成立，那时才需要按赛制「提前把环境和账号调通」。
- 若主办方要求通过在线地址或指定平台打开作品，纯静态双击路线要另做适配。
- 若实测发现某浏览器 `file://` 下完全不给录音权限，主链路应退回「预置转写 + 手动录入」，不要临时引入新库。
